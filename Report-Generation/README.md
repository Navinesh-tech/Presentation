# Report Generation

This section contains selected C# examples related to SAP Business One report generation and email automation.

## Source Code

The source-code folder contains the application entry point and separate processing files for purchase orders, goods receipt POs (GRPO) and A/R invoices.

## Configuration

The configuration example is separated from the source files. Replace all sample values with your own local settings before running any code. Never publish real database or SMTP credentials.

## Before publishing

Confirm that you have permission to share this code. Review it for employer/customer-specific SQL, company names, email addresses, business rules, document details and other proprietary information. Remove or anonymize anything you are not authorized to disclose.
