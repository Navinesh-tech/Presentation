# SAP Business One Portfolio

A collection of selected SAP Business One add-on screens and technical development examples.

## Portfolio Overview

| Project | What it showcases |
|---|---|
| [Employee Issue](Add-ons/Employee-Issue/README.md) | Employee issue screen |
| [Fleet Management](Add-ons/Fleet-Management/README.md) | Vehicle masters, trips, fuel, maintenance, tyres and compliance |
| [Production](Add-ons/Production/README.md) | BOM, production order, job card, route card and subcontracting |
| [Quality](Add-ons/Quality/README.md) | Incoming inspection, in-process rejection, final inspection and scrap approval |
| [Report Generation](Report-Generation/README.md) | C# examples for SAP B1 report automation |

## Technical Areas

- SAP Business One SDK: UI API and DI API
- C# / .NET
- SAP HANA SQL
- SAP Business One Service Layer
- Add-on screen development and business-process-oriented solutions
- Report generation and email automation
